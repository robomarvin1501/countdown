# Countdown player

This is an updated version of a project I started back in 2016. It is designed to play the British TV game show
_Countdown_. There is a player for both the letters games, and the numbers games, called from the file for simply
playing a game "player.py".

One does not need any specific libraries in order to use this, however one does need to run "make" before playing, in
order to generate the sped up numbers game evaluator. This Makefile currently is only tested on Linux based systems, and
may perform incorrectly for you.

The numbers game output is currently in RPN.
